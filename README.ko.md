# nextop 튜토리얼

[nextop](https://pypi.org/project/nextop/)으로 따라 만드는 예제 프로젝트입니다. 버전 폴더마다 그 nextop 버전에 맞춰 만든 튜토리얼이 영어, 한국어, 일본어로 들어 있고, 튜토리얼마다 시험한 nextop 버전이 고정되어 있습니다.

[English](README.md) | 한국어 | [日本語](README.ja.md)

- 홈페이지: https://nextop.nextopologix.com
- 유튜브 (튜토리얼 영상): https://www.youtube.com/@nextopologix

| 버전 | nextop | 튜토리얼 |
|---|---|---|
| [`v0.4.0/`](v0.4.0/) | 0.4.0 (`pip install nextop==0.4.0`) | [한국어](v0.4.0/ko/), [영어](v0.4.0/en/), [일본어](v0.4.0/ja/): 헤어샵 예약 상담, 주가 전망 메일, PDF A4 요약, MCP 서버로 링크 요약, PDF를 PPT로 |

[`v0.4.0/README.ko.md`](v0.4.0/README.ko.md)부터 보세요. Windows에서는 튜토리얼 폴더의 `setup.bat`을 실행하면 그 튜토리얼에 필요한 라이브러리(고정된 nextop 포함)를 `.venv`에 설치하고, `.env.example`로 `.env`를 만듭니다. API 키는 `.env`에 직접 넣습니다.

## 라이선스

이 저장소의 튜토리얼 파일은 [MIT 라이선스](LICENSE)입니다. 튜토리얼이 돌아가는 nextop 플랫폼은 별도 패키지이며 자체 라이선스를 따릅니다([PyPI의 nextop](https://pypi.org/project/nextop/)).
