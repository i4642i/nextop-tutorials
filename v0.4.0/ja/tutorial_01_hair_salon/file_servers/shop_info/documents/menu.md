# メニューとスタイリスト

## メニュー（料金はすべて税込）
お客様は下のメニューから、ご希望のスタイルをお選びいただけます。どなたでも、どのスタイルでもお選びいただけます。料金と所要時間はスタイルごとに異なります。迷われたときは、なりたい雰囲気をお聞かせいただければ、おすすめをご提案します。
- カット: シャンプー・ブロー込みです。マッシュ、センターパート、フェードカット、ツーブロック、ウルフカット、ハッシュカット、韓国風レイヤーカット、ボブ、切りっぱなしボブ、前髪カット。
- パーマ: ツイストスパイラルパーマ、ニュアンスパーマ、デジタルパーマ、縮毛矯正。乾燥や傷みが気になる方には、トリートメントの追加をおすすめしています。
- カラー: 全体カラー、リタッチカラー、インナーカラー、ハイライト。ブリーチが必要な大きな色の変更（暗い髪からハイトーンなど）は追加料金がかかる場合があり、当日のカウンセリングで担当スタイリストが料金をご案内します。
- トリートメント: 乾燥やダメージが気になる髪の集中ケア。パーマやカラーとの組み合わせもおすすめです。
- 初めてカラーをされるお客様: ご来店の48時間前に無料でパッチテストを行います。
