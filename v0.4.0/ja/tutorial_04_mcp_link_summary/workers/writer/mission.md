## 作業の手順

1. 時刻ツール（time__get_current_time）を timezone "Asia/Seoul" で呼び、今日の日付と曜日を確認します。
2. 依頼（request）のページとユイのメモ（notes）をページ番号で組み合わせ、下の形の報告書を書きます。アドレスは依頼（request.pages[].url）から一字一句そのまま書き写します。
3. ファイル書き込みツール（filesystem__write_file）で保存します。path には依頼の report_file（ファイル名だけ）をそのまま書き、content には報告書の全文を入れます。
4. report を保存します。

## 報告書の形

```
# リンク要約 · 2026-11-25 (水)

## 1. <ページのタイトル>
アドレス: <依頼のアドレス>
- <要点>
- <要点>
- <要点>

## 2. ...

## ひとことで
<すべてのページをまとめた1〜2文>
```

- 日付は時刻ツールが返した今日の日付（YYYY-MM-DD）と曜日（月〜日の1文字）です。
- ページは依頼の番号順にすべて書きます。読めなかったページは、タイトルの位置に「読めなかったページ」と書き、アドレスの次の行に「- 読めませんでした: <理由>」だけを書きます。
- 要点はユイのメモ（points）を使います。メモの要点1つを箇条書き1行にし、分けたりまとめたりしません（1ページに3行）。ぎこちない言い回しだけを整え、メモにない内容は付け加えません。
- 要点と「ひとことで」は、報告書らしく常体（だ・である調）でそろえます。

## 各項目の書き方

### report

- file: 依頼の report_file をそのまま書きます。
- headline: 報告書全体を日本語の1文で（件名なので体言止めでもかまいません）。メールの件名になります。

## 守ること

- すべて日本語で書きます（ページのタイトルはページのまま）。韓国語や中国語（簡体字）を混ぜません。
- 保存したファイルはプログラムが読んで検査します（アドレスがすべてあるか、今日の日付があるか）。合っていなければ理由が返ってくるので、直してもう一度保存します。
