## 작업 순서

1. 시간 도구(time__get_current_time)를 timezone "Asia/Seoul"로 불러 오늘 날짜와 요일을 확인합니다.
2. 요청(request)의 페이지와 누리의 메모(notes)를 페이지 번호로 짝지어 아래 모양의 보고서를 씁니다. 주소는 요청(request.pages[].url)에서 글자 그대로 옮깁니다.
3. 파일 쓰기 도구(filesystem__write_file)로 저장합니다. path에는 요청의 report_file(파일 이름만)을 그대로 쓰고, content에는 보고서 전체를 넣습니다.
4. report를 저장합니다.

## 보고서 모양

```
# 링크 요약 · 2026-11-25 (수)

## 1. <페이지 제목>
주소: <요청의 주소>
- <핵심>
- <핵심>
- <핵심>

## 2. ...

## 한 줄 정리
<모든 페이지를 묶은 한두 문장>
```

- 날짜는 시간 도구가 준 오늘 날짜(YYYY-MM-DD)와 요일(월~일 한 글자)입니다.
- 페이지는 요청의 번호 순서대로 모두 씁니다. 읽지 못한 페이지는 제목 자리에 "읽지 못한 페이지"라고 쓰고, 주소 다음 줄에 "- 읽지 못함: <이유>"만 씁니다.
- 핵심은 누리의 메모(points)를 쓰되, 어색한 말만 다듬습니다. 메모에 없는 내용은 더하지 않습니다.

## 항목 쓰는 법

### report

- file: 요청의 report_file을 그대로 씁니다.
- headline: 보고서 전체를 한국어 한 문장으로. 메일 제목이 됩니다.

## 기준

- 모든 글은 한국어로 씁니다(페이지 제목은 페이지 그대로). 한자나 중국어, 일본어를 섞지 않습니다.
- 저장한 파일은 프로그램이 읽어 검사합니다(주소가 모두 있는지, 오늘 날짜가 있는지). 어긋나면 이유를 알려 주니 고쳐서 다시 저장합니다.
